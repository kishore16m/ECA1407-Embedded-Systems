\# Wearable Fitness Tracker using Embedded C



An Embedded C simulation of a wearable fitness tracker using Arduino Uno and Wokwi. The system processes sensor data in real time and displays heart rate, body temperature, step count, and calories burned on an OLED display.



\## Features



\- Real-time heart rate monitoring

\- Body temperature monitoring

\- Step counting

\- Calories calculation

\- OLED display output

\- Wokwi online simulation



\## Components



\- Arduino Uno

\- SSD1306 OLED Display

\- 2 × Potentiometers

\- Push Button



\## Software



\- Embedded C

\- Arduino Framework

\- Wokwi Simulator



\## Files



\- `sketch.ino` – Embedded C source code

\- `diagram.json` – Circuit connections

\- `images` – Circuit and output screenshots

\- `docs` – Project report



\## Simulation



Run the project in Wokwi by importing `diagram.json` and `sketch.ino`.



\## Output



\- Heart Rate (BPM)

\- Temperature (°C)

\- Step Count

\- Calories Burned
