# GPIO Control Using Register-Level Bit Manipulation

An Embedded C project demonstrating efficient GPIO control using direct register-level programming and bit manipulation techniques.

## Features

- Register-level GPIO programming
- Bitwise operations
- LED control
- Button input detection
- Serial Monitor output
- High-speed GPIO access

## Bitwise Operations Used

- OR (`|`) – Set Bit
- AND (`&`) – Clear Bit
- XOR (`^`) – Toggle Bit
- NOT (`~`) – Bit Inversion

## Components Used

- Arduino Uno
- 3 LEDs
- Push Button

## Pin Configuration

| Component | Pin |
|----------|-----|
| Button | D2 |
| LED 1 | D8 |
| LED 2 | D9 |
| LED 3 | D10 |

## Software

- Wokwi Online Simulator
- Embedded C (Arduino)

## How to Run

1. Open the project in Wokwi.
2. Start the simulation.
3. Observe the LED sequence.
4. Press the push button to toggle the LEDs.
5. View the Serial Monitor output.
